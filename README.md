Práctica de Mapeo y Secuencia de 5 LEDs con Raspberry Pi
Proyecto desarrollado para la materia de Sistemas Embebidos, enfocado en el direccionamiento individual de pines GPIO (efecto de desplazamiento o "coche fantástico") utilizando Python y la librería gpiozero en una Raspberry Pi.
📋 Descripción del Proyecto
Este script controla una formación lineal de 5 LEDs conectados a pines consecutivos de la Raspberry Pi. Realiza un ciclo continuo de ida y vuelta (efecto rebote) encendiendo un LED a la vez mediante retardos controlados de tiempo, demostrando el control de matrices o secuencias lógicas de hardware.
